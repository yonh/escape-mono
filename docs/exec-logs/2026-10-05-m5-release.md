# exec-log: M5 收尾——Release 打包

日期：2026-10-05 · 分支：feat/m5-release

## 干了什么

- `game/export_presets.cfg`：macOS（universal .app zip）/ Windows Desktop
  （x86_64 exe+pck）/ Linux（x86_64，embed_pck 单文件）三预设，bundle
  id `com.yonh.escape-mono`，版本 0.1.0。
- `tools/export.sh`：`bash tools/export.sh [macos|windows|linux|all]`——
  headless --export-release 三平台 → `builds/release/escape-mono-{macos,windows,linux}.zip`。
- `.github/workflows/release.yml`：tag `v*` 触发（PR 不参与——保住快门槛约定），
  setup-godot 4.7 + 下载导出模板 → export.sh all → action-gh-release 上传三 zip。
- `project.godot`：`import_etc2_astc=true`（universal/arm64 导出模板硬性要求）。
- `.gitignore`：+builds/。

## 验证

- 本机三平台导出全部成功：macos.zip 57M（.app 内嵌 pck 633KB——程序
  合成资产体积小）、windows.exe 104M+pck 619K、linux.x86_64 71M 单文件。
- 解压 macos.app 二进制 `--version` 输出 4.7.stable——包体可运行。
- 导出模板安装：tpz 解压目录名必须是 `export_templates/4.7.stable`
  （非编辑器装的 .official.hash 长尾名）——本机手命名同样生效。

## friction

- 导出模板 1.2GB 首次下载+解压耗时；CI 每跑必下，如需更快可加 cache
  （key=godot-4.7-stable）；当前 tag 频率低未加。
- macOS 导出无签名（codesign 关）——用户首启需右键打开/移除 quarantine；
  文档/Release 说明里写一句即可，正式分发再配 Apple Developer 证书。
- export_presets.cfg 的 macOS options 字段冗长（签名/隐私键全开默认），
  手写易错——后续若编辑器里改过导出预设，以 GUI 为准重导一遍。
