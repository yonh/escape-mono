# 执行日志：M4 音效子集——全链游戏音

- 日期：2026-10-05
- 分支：feat/m4-audio（从 main@M2 合并后拉出）
- 里程碑：M4 氛围 · 音效子集

## 目标

游戏此前完全无声——枪声/命中/脚步/交互音是最大的可玩性缺口。
按 manifest 台账规范，用程序合成 CC0 资产补齐 15 个音效并接线。

## 交付

- `tools/gen_audio.py`：stdlib-only WAV 合成器（确定性种子；shot/thud/
  footstep/rustle/ambient/door 等配方；amb 循环做了尾部交叠）。
- 15 个 wav 登记 manifest `status: integrated`（CC0-1.0，source=generated，
  脚本即来源）→ `sync_assets.py` 入 `game/assets/audio/`。
- `game/scripts/gameplay/sfx_kit.gd`：stream 缓存 + play_2d/play_3d
  （finished→queue_free 自清理）+ loop_2d（常驻）+ gunshot_for(weapon_id)。
- 接线点：
  - `raid_game`：环境底噪循环、枪声（按 weapon_id 选型）、换弹、受击命中、
    阵亡 sting、撤离 chime、开箱
  - `scav_ai`：3D 枪声（sfx_shot_scav）、3D 倒地
  - `locked_door`：开门/拒绝 3D
  - `searchable`：搜索循环音自治（begin 开 / finish·cancel·search_now 停），
    世界箱与尸体箱全覆
  - `fps_controller`：按位移累计的脚步（走 1.6m / 跑 2.2m 一步）
- `tools/test_sfx.gd`：headless smoke——15 流可载、选型正确、player
  生命周期、searchable 循环音创建/清理。

## 验证

- `godot --import` 无 SCRIPT ERROR；9+1 个 headless 测试全过。
- `check_manifest.py`：19 assets OK。
- 真机 playtest：日志无音频错误；[NAV]/[FIRE]/[AI] 遥测正常（见 PR 评论）。

## friction

- headless 用 dummy 音频驱动：`finished` 信号不可靠发出——测试只断言
  playing/stream/生命周期标记，不 await finished。
- 搜索循环音有 4 个结束路径（tick 完成/cancel/search_now/free），容易漏停；
  收敛为 `_stop_search_sfx()` 单点，全部路径调用。
- 回忆坑（M2 exec-log 沿用）：`-s` 脚本下 `get_tree().current_scene` 为 null，
  所有播放器都挂到调用方自身节点下。
- **本 VM 无音频设备**：CoreAudio init 失败 → 全驱动回退 dummy（`audio_server
  falling back to the dummy driver`），真机窗口模式也发不出声——音效只能
  以「代码路径执行无报错 + headless 生命周期断言」验证，无法听感确认。
  音量/衰减曲线留给有音频设备的机器复调。
