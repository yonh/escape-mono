# ROADMAP

游戏概念：3D 第一人称密室逃脱。探索房间 → 找线索/道具 → 解谜 → 开门逃出。
每个里程碑交付「可玩 + 可验证」的东西；资产随里程碑从灰盒逐步替换。

- [x] **M0 骨架**：可运行的灰盒房间、第一人称控制器、交互射线、占位门/钥匙卡、monorepo + 工作流落地。
- [ ] **M1 第一个谜题闭环**：钥匙卡真正开门（背包或拾取状态 → 门判定 → 开门动画/音效 → 过关画面）。资产：门/卡模型 + 开关门音效替换占位。
- [ ] **M2 房间一**：完整设计一间密室（3-4 个关联谜题、纸条线索、道具组合）。资产管线跑通一遍「needed → 生成 → integrated」全流程。
- [ ] **M3 氛围**：灯光方案、墙面/地面 PBR 贴图、环境音与交互音效、简单 UI（物品栏/提示）。
- [ ] **M4 打磨与发布**：主菜单/存档/设置、性能与导入检查脚本化、itch.io 或 GitHub Release 发布流程。
