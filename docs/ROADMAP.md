# ROADMAP

游戏概念：3D 第一人称「类塔科夫」逃离游戏（2026-10 起按用户指示转向，ADR-0004）。
生存屋整备 → 出发进 raid → 搜刮/开箱 → 撤离成功物资入库（阵亡/超时丢包）。
每个里程碑交付「可玩 + 可验证」的东西；资产随里程碑从灰盒逐步替换。

- [x] **M0 骨架**：灰盒房间、第一人称控制器、交互射线、monorepo + 工作流落地。
- [x] **M1 raid 循环 + 工厂关卡**（ADR-0004，移植自 yonh/godot_escape）：
  生存屋（储物箱/装备台/出发垫）→ 工厂室内 CQB 图（48×36m，3 撤离 3 出生 13 箱位）
  → 8 秒撤离读条 / 15 分钟 MIA 超时 / 阵亡丢包回生存屋；
  库存网格 UI、装备槽（主/副武器·护甲·背包）、武器射击、血量、loot 搜索全链。
