# 工厂关卡（factory_map.gd）

类塔科夫"工厂"图：一座 48×36m 全封闭厂房，室内 CQB 节奏（15 分钟局）。
布局数据驱动（`LAYOUT` / `CRATES` / `EXTRACTS` / `SPAWNS` / `LIGHTS`），
全部使用 prop_kit 白盒占位，真实资产到位后按 kind 替换即可。

## 平面结构

```
        北外墙
 ┌────────┬─────────┬──────┬─────────┐
 │ 办公室 │ 会议室  │ 机房 │ 储藏间  │   办公区（z -18..-11.6，4m 吊顶）
 ├────────┴─────────┴──────┴─────────┤
 │        北  廊（办公区门前）         │   z -11.6..-7.5
 ├───┬───────────────────────────┬───┤
 更衣│                           │危险品库
 ├───┤       主  车  间          ├───┤   大厅 x -8.5..13.5, z -7.5..8.5
 车间│  立柱阵·机床列·储罐        │   │   6m 通高，东侧二层钢平台
 ├───┤  二层平台(西缘护栏)        │备件间
 │   │        坡道↑              │   │
 库房│                           │   │
 ├───┴───────────────────────────┴───┤
 │        南  廊                     │   z 8.5..12.5
 ├───────────────────────────────────┤
 │   装卸区（集装箱/叉车/GATE-0）    │   z 12.5..18，5m 吊顶
 └───────────────────────────────────┘
   西廊 x -12..-8.5 · 东廊 x 13.5..17.5（4m 吊顶）
```

- **主车间**：2×3 承重柱阵 + 两列机床形成中央巷道 + 西墙储罐；
  东墙内侧 14m 二层平台（elev 2.7，西缘护栏），南端大厅中央 6m 坡道上桥。
- **环廊**：北/西/东/南四条走廊连通所有房间，门洞全部留道。
- **办公区**：北排四间（办公室/会议室/机房/储藏间），南门开向北廊。
- **西翼**：更衣室（出生点+货运电梯撤离）/车间/库房；库房与装卸区之间
  是大开间通道（物流口）。
- **东翼**：危险品库（储罐+桶）/备件间，西墙开门通东廊。

## 游戏流程

- **撤离（3 处，8 秒读条）**：正门 GATE-0（装卸区南墙卷帘门）、
  东门 GATE-3（东廊尽头卷帘门）、货运电梯（更衣室西墙）。
- **出生（3 处随机，`plan["spawn_idx"]` 可指定）**：更衣室 / 装卸区 / 东北走廊口。
- **物资箱 13 处**：散布各房间（含二层平台上一只 cache——爬桥奖励），
  table 对应 loot_table（cache/medkit/food/toolbox/valuable）。
- **计时**：`RAID_SECONDS=900`（15 分钟）。HUD 左上"剩余时间 mm:ss"，
  归零判 MIA——等同阵亡：背包清空、计 departed 不计 completed，3.5 秒后回生存屋。
- **出发**：生存屋单块出发垫「出发 DEPART → 工厂」，`game_state.raid_map_id` 写入 factory 后切 raid 场景。

## 性能约定

- 室内图无昼夜/太阳：`build()` 返回 `indoor:true`，raid_game 走
  `_build_indoor_lighting`（深色环境底光），照明全部来自 `LIGHTS` 的
  OmniLight 阵列（`shadow_enabled=false` 保帧率）+ lamp 道具发光灯泡。
- 吊顶分区：大厅 6m / 房间走廊 4m / 装卸区 5m，天空壳外仍铺地面兜底。
